# 🤖 TitanBot Command Registry


### 📂 Birthday
- **`/birthday`**: Birthday system commands

### 📂 Community
- **`/app-admin`**: Manage staff applications
- **`/apply`**: Manage role applications

### 📂 Core
- **`/bug`**: Report a bug or issue with the bot
- **`/help`**: Displays the help menu with all available commands
- **`/overview`**: Read-only snapshot of all server system statuses.
- **`/ping`**: Checks the bot's latency and API speed
- **`/stats`**: View bot statistics
- **`/support`**: Get link to the support server
- **`/uptime`**: Check how long the bot has been online

### 📂 Economy
- **`/balance`**: Check your or someone else's balance
- **`/beg`**: Beg for a small amount of money
- **`/buy`**: Buy an item from the shop
- **`/daily`**: Claim your daily cash reward
- **`/deposit`**: Deposit money from your wallet into your bank
- **`/eleaderboard`**: View the server's top 10 richest users.
- **`/inventory`**: View your economy inventory
- **`/pay`**: Pay another user some of your cash
- **`/profile`**: Generates your custom Dynamic ID Passport.
- **`/shop`**: Economy shop commands.
- **`/withdraw`**: Withdraw money from your bank to your wallet

### 📂 Fun
- **`/fight`**: Starts a simulated 1v1 text-based battle.
- **`/roll`**: Rolls dice using standard notation (e.g., 2d20, 1d6 + 5).

### 📂 Giveaway
- **`/gcreate`**: Starts a new giveaway in a specified channel.
- **`/gdelete`**: The message ID of the giveaway to delete.
- **`/gend`**: The message ID of the giveaway to end.
- **`/greroll`**: Rerolls the winner(s) for an ended giveaway.

### 📂 JoinToCreate
- **`/jointocreate`**: Manage Join to Create voice channels system.

### 📂 Leveling
- **`/leaderboard`**: Shows the server's level leaderboard
- **`/level`**: Manage the leveling system
- **`/leveladd`**: Add levels to a user
- **`/levelremove`**: Remove levels from a user
- **`/levelset`**: Set a user's level to a specific value
- **`/rank`**: Check your or another user's rank and level

### 📂 Logging
- **`/logging`**: Manage audit logging for this server.

### 📂 Moderation
- **`/ban`**: Ban a user from the server
- **`/cases`**: View moderation cases and audit logs
- **`/dm`**: Send a direct message to a user (Staff only)
- **`/kick`**: Kick a user from the server
- **`/massban`**: Ban multiple users from the server at once
- **`/masskick`**: Kick multiple users from the server at once
- **`/purge`**: Delete a specific amount of messages
- **`/timeout`**: Timeout a user for a specific duration.
- **`/unban`**: Unban a user from the server
- **`/untimeout`**: Remove timeout from a user
- **`/usernotes`**: Manage user notes for moderation purposes
- **`/warn`**: Warn a user
- **`/warnings`**: View all warnings for a user

### 📂 Reaction_roles
- **`/reactroles`**: Manage reaction role assignments

### 📂 Search
- **`/define`**: Look up a word definition
- **`/google`**: Search Google
- **`/movie`**: Search for a movie or TV show
- **`/urban`**: Search Urban Dictionary for definitions

### 📂 ServerStats
- **`/serverstats`**: Manage server statistics that track member counts and channel data

### 📂 Ticket
- **`/claim`**: Claims an open ticket, assigning it to you.
- **`/close`**: Closes the current ticket.
- **`/priority`**: Sets the priority level for the current support ticket.
- **`/ticket`**: Manages the server's ticket system.

### 📂 Tools
- **`/backup`**: Creates a full JSON backup of the server layout (Channels, Roles, Categories).
- **`/baseconvert`**: Convert numbers between different bases
- **`/calculate`**: Evaluate a mathematical expression
- **`/countdown`**: Start a countdown timer
- **`/embedbuilder`**: *(Empty — use the menu below to add content)*
- **`/feed`**: Pulls the top trending post from any Subreddit.
- **`/generatepassword`**: Generate a strong, random password
- **`/hexcolor`**: Generate a random hex color with preview
- **`/imagine`**: Generates a high-resolution AI image from a text prompt.
- **`/poll`**: Create a simple poll with up to 10 options
- **`/prometheus`**: Engage with the Autonomous Neural Engine
- **`/randomuser`**: Select a random user from the server
- **`/reply`**: Replies to a user via Modmail.
- **`/review`**: Summons the AI to roast and fix your terrible code.
- **`/shorten`**: Shorten a URL using is.gd
- **`/time`**: Get the current time in different timezones
- **`/tldr`**: Summons the AI to summarize the last 100 messages in this channel.
- **`/unixtime`**: Get the current Unix timestamp
- **`/wormhole`**: Connects this channel to the Global Inter-Server Chat.

### 📂 Utility
- **`/avatar`**: Display a user's avatar image
- **`/firstmsg`**: Get a link to the first message in this channel
- **`/report`**: Report a user to server staff, or configure where reports are sent.
- **`/serverinfo`**: Get detailed information about the server
- **`/todo`**: Manage your personal to-do list
- **`/userinfo`**: Get detailed information about a user
- **`/weather`**: Get real-time weather information for a location
- **`/wipedata`**: Delete all your personal data from the bot (irreversible)

### 📂 Verification
- **`/verification`**: Manage the server verification system
- **`/verify`**: Verify yourself and gain access to the server

### 📂 Voice
- **`/activity`**: Start a Discord Activity in your voice channel
- **`/radio`**: Toggles the 24/7 Lofi Hip-Hop Radio in your voice channel.

### 📂 Welcome
- **`/autorole`**: Manage roles that are automatically assigned to new members
- **`/goodbye`**: Configure the goodbye message system
- **`/greet`**: Manage welcome & goodbye settings
- **`/welcome`**: Configure the welcome system
