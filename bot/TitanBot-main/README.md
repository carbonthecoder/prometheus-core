## ⚙️ How to Steal My Setup

Want to run this yourself? Follow the steps, assuming you actually know how to use a terminal.

1. **Clone it down**
```bash
git clone https://github.com/your-username/Project-Prometheus.git
cd Project-Prometheus
```

2. **Install the packages**
```bash
npm install
```

3. **Set up the Environment**
Rename `.env.example` to `.env`. You'll need a Discord Token and a free Gemini API Key.
```env
DISCORD_TOKEN=your_token_here
GEMINI_API_KEY=your_gemini_key_here
POSTGRES_URL=your_postgres_url
```

4. **Fire it up**
```bash
npm start
```
